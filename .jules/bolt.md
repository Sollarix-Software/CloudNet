## 2026-10-20 - Fast-path check and regex pattern caching in ConsoleColor formatting
**Learning:** `ConsoleColor.toColoredString` and `ConsoleColor.stripColor` are called frequently for console logging and input processing. Compiling regex patterns like `Pattern.compile(triggerChar + "#([\\da-fA-F]){6}")` repeatedly on every log string causes substantial regex compilation overhead and GC allocation pressure. Adding fast-path short-circuit checks (`input.indexOf(triggerChar) == -1` and `input.indexOf('#') == -1`) completely avoids regex and StringBuilder allocation for plain text. Pre-compiling static Patterns and caching dynamic ones in a thread-safe Map eliminates redundant regex compilations.
**Action:** When handling hot-path string formatting or log transformations, always check for character presence before instantiating `StringBuilder` / `Pattern` matchers, and cache compiled `Pattern` instances.
